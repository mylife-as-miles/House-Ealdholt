# Crownfall autumn settlement

Crownfall owns the terrain and routes, the compound Banner Hall, heraldic placement, exploration and building editor. These use the existing renderer-neutral geometry kit and material library. The runtime [combined source kit](../../worlds/combined/SOURCE.md) supplies actual adapted Athenaion cottages, Golden Temple court/player pavilions, Monolith Wilds woodland/rocks/ruins, and original Crownfall estate water. Its provenance records distinguish those source assets from original Crownfall arrangements; they are not all original Crownfall geometry.

The estate editor places buildings only. Crops, planted fields and farming controls have been removed. Loading an older v1 estate filters retired field records in memory while preserving valid buildings; only a later building edit writes the cleaned layout. The Legacy house save and chess progression are separate.

Visual direction was compared with the public Winter Cats Studios settlement-building clip:
https://x.com/wintercatsgames/status/2117604973844267444

The reference informed aerial composition, autumn colours, compact charcoal/brass panels and placement feedback. Its footage, models, textures, logos, place names and simulation code are not redistributed as Crownfall assets. Reference media is retained outside the repository for inspection only.

The four other Legacy environments retain their own source/provenance files. The three MIT source notices remain alongside their vendored code. The unlicensed Alpine source adaptation is excluded from this public tree; the estate uses original Crownfall water. The creator's reported permission remains unverified for redistribution. This presentation does not change upstream licences.
