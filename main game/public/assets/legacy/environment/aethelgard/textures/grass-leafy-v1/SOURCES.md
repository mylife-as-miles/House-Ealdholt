# Leafy Grass ground material

Powered by Poly Haven. Leafy Grass — Charlotte Baglioni: https://polyhaven.com/a/leafy_grass . CC0-1.0; official licence https://polyhaven.com/license . Legal code is included in CC0-1.0.txt.

Actual trampled grass with scattered brown litter, photographed as a2m tile. This is optional original outside-valley ground treatment, not recovered village landscape painting. Albedo chroma is retained. Desktop uses1024px maps, Quest512px maps; OpenGL normals and linear ARM stay aligned. Full mip-chain RGBA8 byte figures are added owned estimates, not physical GPU or net-memory measurements.

Source URLs, fixed official MD5/size checks and source/derived SHA256 hashes are in provenance.json/manifest.json. Original downloads remain outside the repository. Reproduce with node scripts/prepare-ealdholt-grass-ground.mjs PRIVATE_INTAKE_DIRECTORY NEW_OUTPUT_DIRECTORY . No runtime requests occur unless the caller invokes the canonical grass-map loader.
