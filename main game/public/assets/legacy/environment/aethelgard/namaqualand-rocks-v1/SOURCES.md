# Namaqualand boulder scans

Poly Haven models `namaqualand_boulder_02`, `_04`, `_06`, from the requested Namaqualand collection. CC0: https://polyhaven.com/license . Source file URLs, provider MD5 checks, SHA-256 digests and derived file sizes are recorded in manifest.json. Geometry is recentered to ground contact, normalized to a two-metre maximum dimension and simplified offline. Original UVs and scanned albedo, OpenGL normal and ARM maps are preserved at 512 pixels. No reference world or settlement geometry is imported. Rebuild: `node scripts/environment/build-regional-rocks.mjs`.
